# Синтетические данные

Каталог для общих синтетических наборов данных, используемых в разработке и проверках. Сейчас содержит только это описание.

Примеры для проверки формы API-данных уже находятся в `contracts/examples/` и остаются там; описание — в [contracts](../contracts/README.md).

Для добавляемых наборов указывайте назначение, сценарий использования и способ загрузки. Используйте вымышленные данные без персональной информации и секретов.

## be3-05

`be3-05/control-values.json` — зафиксированные контрольные значения по дням для трёх синтетических профилей BE3-05
(seed `20260916`, старт `2026-09-14`). Данные вымышленные и учебные. Загрузка — `:backend:api:seedDemo`, см.
[backend/api/README.md](../backend/api/README.md).
