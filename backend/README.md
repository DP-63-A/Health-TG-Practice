# Backend

Каталог для реализации backend на Java 21. Выбранный стек: Spring Boot, Spring Web, MongoDB и Liquibase.

Сейчас каталог содержит только документацию: исходники приложения и конфигурация его сборки ещё не добавлены. Каталог не подключён как Gradle-модуль, команд запуска приложения нет.

Существующая общая Gradle-сборка находится в корне репозитория и включает инструмент проверки контрактов. Требования и команды — в [корневом README](../README.md), API-схемы — в [contracts](../contracts/README.md).

Java-тесты каждого будущего модуля размещаются в его `src/test/java/`, ресурсы тестов — в `src/test/resources/`. Общие сквозные проверки продукта относятся к [tests](../tests/README.md).
