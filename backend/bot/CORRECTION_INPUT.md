# Разбор исправлений числа и даты

`CorrectionInputParser` проверяет **весь ввод** одного исправляемого значения. Это самостоятельная часть BE2-06 (#64), без Telegram, БД, выбора поля и изменения записи.

## API

```java
var parser = new CorrectionInputParser();
CorrectionResult<BigDecimal> number = parser.parseNumber("12,50");
CorrectionResult<LocalDate> date = parser.parseDate("29.02.2024");
```

`CorrectionResult.Success<T>.value()` содержит значение. `CorrectionResult.Failure<T>` содержит стабильный код `code()` и русскую подсказку `message()`. Коды: `EMPTY_INPUT`, `INVALID_NUMBER_FORMAT`, `INVALID_DATE_FORMAT`, `INVALID_DATE`. В результате ошибки нет исходного пользовательского ввода. Компонент не ведёт логов.

## Форматы

| Тип | Принимается | Отклоняется |
| --- | --- | --- |
| Число | `12`, `+12`, `-12`, `12.5`, `12,50`, `0012`, `-0.00` | `1 000`, `1,234.56`, `.5`, `12.`, `12 кг`, `1e3`, `NaN`, `Infinity` |
| Дата | `05.10.2026`, `2026-10-05`, `29.02.2024` | `5.10.2026`, `05.10`, `05/10/26`, `вчера`, `31.02.2026`, `29.02.1900`, `0000-01-01` |

Числа используют только ASCII-цифры `0–9`, необязательный ASCII-знак `+`/`-`, не более одной точки или запятой с цифрами с обеих сторон. Запятая **всегда десятичная**: `1,234` означает 1.234, а не 1234. Ведущие нули допускаются. `BigDecimal` сохраняет десятичную точность и количество знаков дробной части; округления нет. Отдельный отрицательный ноль не сохраняется.

Даты используют только ASCII-цифры, двухзначные день/месяц и четырёхзначный год `0001–9999`. `LocalDate` и `ResolverStyle.STRICT` проверяют существование даты в календаре ISO; неверная дата не переносится автоматически на следующий месяц. Часовой пояс и время не вычисляются.

По краям обоих типов удаляются символы, для которых Java `Character.isWhitespace` **или** `Character.isSpaceChar` возвращает true: обычные пробелы, табуляция, переводы строк, NBSP и другие Unicode-пробелы этих категорий. Внутри значения они запрещены. Zero-width space и BOM не удаляются и приводят к ошибке. `null`, пустая строка и строка только из допустимых внешних пробелов дают `EMPTY_INPUT`.

Успешный разбор не означает разрешения сохранить значение в выбранном поле: например, `-5` синтаксически корректно, но может нарушать ограничения массы. Диапазон, целочисленность и другие требования конкретного поля проверяет вызывающий код по контракту. Общего произвольного диапазона или ограничения длины здесь нет; ограничения транспортного ввода относятся к интеграции.

## Ручной запуск без Telegram и БД

Нужен JDK 21. Из корня репозитория в новом окне Windows PowerShell:

```powershell
[Console]::OutputEncoding = [System.Text.Encoding]::UTF8
[Console]::InputEncoding = [System.Text.Encoding]::UTF8
$OutputEncoding = New-Object System.Text.UTF8Encoding $false
New-Item -ItemType Directory -Force backend/bot/build/correction-demo | Out-Null
$correctionSources = Get-ChildItem backend/bot/src/main/java/org/healthtg/bot/correction/*.java | ForEach-Object { $_.FullName }
javac -encoding UTF-8 --release 21 -d backend/bot/build/correction-demo $correctionSources
java -cp backend/bot/build/correction-demo org.healthtg.bot.correction.CorrectionParserDemo
```

Команды предполагают JDK 21 в `PATH`; `javac -version` и `java -version` должны показывать 21. Компиляция помещает классы в игнорируемую папку `build`, сборочные файлы не изменяются. Настройки кодировки действуют только в текущем окне PowerShell.

Введите по очереди:

```text
number 12,50
number 12 кг
number ё🙂
date 29.02.2024
date 29.02.2023
date 05.10
exit
```

Ожидаются число `12.50`, две ошибки формата числа, дата `2024-02-29`, ошибка несуществующей даты и ошибка формата даты. Проверяйте читаемость русских подсказок, `ё` и emoji как в приветствии, так и в строке `Ввод: number ё🙂`. Демонстрация выводит введённую строку для локальной проверки, но не сохраняет её. Пустое значение проверяется строкой `number ` или `date ` с пробелом после команды.

Эти команды проверяют консольный запуск. Кнопка Run в IntelliJ IDEA требует отдельной проверки её настроек ввода/вывода UTF-8 и не подтверждается консольным тестом.
