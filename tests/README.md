# Сквозные проверки

Каталог для сценариев, проверяющих совместную работу частей продукта. Сквозные проверки пока не реализованы, команд запуска для этого каталога нет.

Java-тесты конкретного модуля хранятся рядом с его кодом в `src/test/java/`. Существующие тесты контрактов находятся в `tools/contract-validator/src/test/java/` и запускаются через общую Gradle-сборку: см. [корневой README](../README.md).

При добавлении сквозного сценария опишите необходимые условия, шаги, ожидаемый результат и команду запуска.
