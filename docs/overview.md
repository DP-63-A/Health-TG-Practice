# Обзор (overview): архитектура и контракт 

# Задача: FE2-01 

## 1.  Состав экрана


| # | Элемент | Тип | Что показывает |
|---|---|---|---|
| 1 | Переключатель периода | управление | Сегодня / 7 дней / 21 день |
| 2 | Служебная строка | информация | число дней с данными и время актуальности |
| 3 | Кнопка обновления | управление | переcчитывание данных |
| 4 | Карточка «Калории и БЖУ» | карточка | калории, белки, жиры, углеводы |
| 5 | Карточка «Приёмы пищи» | карточка | количество приёмов пищи |
| 6 | Карточка «Сон» | карточка | кол-во часов сна за период (за сегодня / за 7 дней /за 21 день) |
| 7 | Карточка «Шаги» | карточка | шаги за период (за сегодня / за 7 дней / за 21 день)|
| 8 | Карточка «Пульс» | карточка | пульс |
| 9 | Карточка «Оценки» | карточка | четыре субъективные оценки |
| 10 | График «Питание» | график | ряд по дням |
| 11 | График «Сон» | график | ряд по дням |
| 12 | График «Шаги» | график | ряд по дням |
| 13 | График «Состояние» + переключатель категории | график + управление | ряд по выбранной категории |


## 2. Схема экрана 

Мобильный экран, одна колонка, ширина 360–390 px, без горизонтального скролла.

```
┌──────────────────────────────┐
│ Обзор                        │
│ [Сегодня] [7 дней] [21 день] │
│ Дней с данными: 5 из 7       │
│ Обновлено 14:32          [⟳] │
├──────────────────────────────┤
│ ┌────────────┬─────────────┐ │
│ │ Калории    │ Приёмы      │ │
│ │ + Б / Ж / У│ пищи        │ │
│ ├────────────┼─────────────┤ │
│ │ Сон        │ Шаги        │ │
│ ├────────────┼─────────────┤ │
│ │ Пульс      │ Оценки (4)  │ │
│ └────────────┴─────────────┘ │
├──────────────────────────────┤
│ Питание   ▂▃▅▆▅▃▂            │
│ Сон       ▂▃▅▆▅▃▂            │
│ Шаги      ▂▃▅▆▅▃▂            │
│ Состояние [Категория ▾]      │
│           ▂▃▅▆▅▃▂            │
└──────────────────────────────┘

```
